<h2 align="center">Описания</h2>

<h3>Сейчас работает из функций next, install, ping, store, soft, basket, inputlag</h3>

- next это отдельное окно у нее другие функций они отличаются от Urland main окно которое вас встречает когда запускаете программу next ещё не допилинь и за этого пустой но есть команды exit, back команда back возвращает на Urland main а exit команда прикрашает работу программы.
- install окно для устоновок приложение на ваш компьютер (windows пока что) пока что не чего устоновить нельзя.
- store здесь собрано все онлайн магазины каторые я использовал возможно кому-то будет польезно.
- soft это мини веб сайт где собранны приложенией каторые я знаю и по моему опыту 
- basket если у вас нету корзины на рабочем столе то можно вести эту команду и вас перебросить за корзину 
- inputlag пока что лучшее её не использовать так как не проверил до конца можно сказать что не работает 

<h3> Пока что программа очень слобая но с каждой обновой будет только становится сильнее как и сам разработчик</h3>
